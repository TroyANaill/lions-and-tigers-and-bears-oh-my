# lions-and-tigers-and-bears-oh-my
A website that allows the user to select a dog breed and view a slideshow of their pictures.
Hosted using Azure at this address

Author: Troy Naill
Project: Lions and Tigers and Bears, Oh My
Credits: full credit to Brad Schiff, my code follows "Dogs, JavaScript & An API" tutorial. 

How to run this program:
Clone the repository:
git clone https://github.com/TroyANaill/lions-and-tigers-and-bears-oh-my.git
cd lions-and-tigers-and-bears-oh-my
Serve the folder locally:
  -Double click index.html to open it directly
How to use the app:
  - Select a dog breed from the dropdown menu.
  - A slideshow of images for that breed will begin cycling.
